SaluNet-C-50 / ImageNet-1K

Checkpoint:
salunet-c50-imagenet1k-clamped-swalu-ema-epoch118.pth

Architecture:
53 SALU modules and 17 independent clamped-SWALU modules.
SWALU outputs are clamped to [-10, 10] during training and evaluation.

Checkpoint selection:
EMA weights selected at epoch 118.
Saved best EMA Top-1: 79.416% under the training validation protocol.

Final evaluation:
Original 50,000 ImageNet-1K validation images.
Online bilinear resizing followed by center cropping.

224 x 224:
Resize shorter side to 240 pixels.
Top-1: 79.588%
Top-5: 94.586%

288 x 288:
Resize shorter side to 320 pixels.
Top-1: 80.158%
Top-5: 94.964%

Both resolutions use the same selected EMA checkpoint.
No additional training or fine-tuning is performed.

Run the following commands from the SaluNet repository root.

Evaluation at 224 x 224:

python imagenet/salunet-c-50/evaluate_salunet_c50_ema.py \
  --checkpoint salunet-c50-imagenet1k-clamped-swalu-ema-epoch118.pth \
  --data-root /path/to/imagenet/val \
  --resize-size 240 \
  --crop-size 224 \
  --batch-size 128 \
  --num-workers 4

Evaluation at 288 x 288:

python imagenet/salunet-c-50/evaluate_salunet_c50_ema.py \
  --checkpoint salunet-c50-imagenet1k-clamped-swalu-ema-epoch118.pth \
  --data-root /path/to/imagenet/val \
  --resize-size 320 \
  --crop-size 288 \
  --batch-size 128 \
  --num-workers 4
